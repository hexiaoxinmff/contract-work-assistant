# 合同检查与对比结果展示

按任务及用户指定格式选择，通常直接在聊天中给 Markdown 表格，无需图片或绘图库。每项保留准确来源和可定位信息；只引用任务需要的少量原文。用户只问一个事实时可用简短文字，不凑表、不额外扩大审查。状态要有文字，颜色或图标仅作辅助，不把图标当作法律风险评级或审核结论。

## 检查状态表

建议字段：检查项目｜原文/位置｜状态｜原因与建议或待确认事项。状态仅按实际依据选择：

- **明确问题**：已核实具体错误或材料间直接矛盾，列双方原文和位置。
- **待确认**：文字含糊、疑似错误、口径或事实不足，不把猜测写成已发生问题。
- **已检查，未见明确问题**：只适用于实际检查过且结果有依据的特定项目；不表示整份合同无风险或已获批准。
- **未检查**：材料未提供、页面不可读或工具不可用，说明范围及原因；不标为通过。

没有问题的类别只在用户需要或有助理解时列出；不因表格需要而编造项目或“零问题”。金额差异若不知道是否为同一笔款项，标待确认。

## 条款左右对照表

建议字段：事项｜材料甲原文摘要及位置｜材料乙原文摘要及位置｜差异/待确认。逐项对应实际任务，并标明不同供应商的正常约定差异，不自动认定错误；只凭相同标题无法证明内容相同。未提供、未约定、不可读取应按事实分别标记，不能误用空白或“无”。必要时简述已读范围与未读内容。

## 报价图：按需且必须可比

先展示报价、单位、币种、服务范围、数量、期间、税费和额外费用等影响结论的已知条件与出处；按任务选择关键项。只有已知材料充分支持采用同一比较口径，或根据明确数据与公式换算后可比时，才用可用绘图工具画柱状图/条形图；写明数值、单位、比较口径、计算方法、来源和必要限制。条件不明或不同时，用对照表列出差异和待确认项，不用把价格高低画成可直接比较的图，不把未提供当作零。不能仅凭价格推荐最优方案。

## 时间轴：按需且标记不确定性

仅使用材料中明确写出的具体日期及对应事件与出处，按实际日期排序。无年份、仅有每月某日、条件触发或双方日期冲突时不猜测、不错画在确定位置；可用表格列出原文与待确认事项。区间的起止和事件性质要清楚，不根据日期自动判定逾期或履行完成。

## 绘图依赖检查与按需安装

1. 判断本次是否确需实际图像或文件；聊天表格足以满足需求时，不为绘图安装。确认当前平台、解释器、现有绘图能力与目标输出位置，能复用已有能力时不安装。
2. 缺少任务必需的绘图库且本次用户未禁止安装、联网或环境变更时，可在平台许可和当前权限内自动安装该必要依赖，不必逐次请求确认。优先平台提供的隔离运行环境，使用官方可信的包来源；先识别解释器及目标安装位置，避免修改系统全局环境、升级或卸载其他包，不安装无关工具，不传送合同或报价内容给包来源。包下载会访问网络，网络受限或用户禁止时不能绕过。现有依赖安装路径或权限不明、只能改变系统全局环境时，停止自动安装并说明。
3. 安装后在实际用于绘图的解释器中验证导入、版本与安装位置；真正生成图片后确认输出文件存在，并检查图中数据、单位、日期及可读性。结果中简短报告有无新安装、包名、版本、目标环境/位置、验证结果和已生成的文件；不把导入成功说成图片已生成。
4. 安装或验证失败时停止重复尝试，说明可完成和未完成部分，优先用现有能力或聊天表格；不得声称成功。该流程只覆盖本次绘图所需依赖，不表示已内置 OCR 或授权安装 OCR 系统及模型。

## 文件、能力与保密

聊天表格不等于另存文件。用户要求导出时，先确认当前会话有实际生成能力、目标格式及本次授权；结果不得覆盖原件。任何图表/文件应尊重只读及不存储要求，避免未经允许创建中间文件、外发到额外服务；用户要求平台零留存而无法保证时，按技能隐私边界停止。工具未调用或无法绘图时明确说明并给可在聊天阅读的表格，不虚构已创建的图片或文件。
